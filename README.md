# Student Academic Performance Analysis

## Project Overview
This project analyzes student academic performance using Microsoft Power BI. The dashboard provides insights into students' marks, grades, attendance, and pass percentage.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Dataset
- 200 simulated student records
- Student details
- Subject-wise marks
- Attendance percentage
- Grades and results

## Dashboard Features

### KPI Cards
- Total Students
- Average Marks
- Pass Percentage
- Average Attendance

### Visualizations
1. Average Marks by Subject
2. Pass vs Fail Distribution
3. Average Performance by Class
4. Grade Distribution
5. Attendance vs Academic Performance
6. Top 10 Students by Average Marks

### Interactive Filters
- Class
- Gender
- Grade
- Result

## Key Insights
- Overall student performance can be compared across subjects.
- Pass and fail distribution can be analyzed.
- Grade distribution helps understand academic performance.
- Attendance can be compared with academic marks.
- Top-performing students can be identified.

## Project Purpose
To develop practical data analysis and dashboard-building skills using Power BI.

**Note:** This project uses simulated data for educational and portfolio purposes.
